# Lanna Calendar

ปฏิทินล้านนา (มื้อจั๋นวันดี) แสดงวันล้านนา วันไท วันเก้ากอง ฟ้าตีแส่ง ดิถี และวันสำคัญตามตำรา

## วิธีคำนวณ (Calculation)

ค่าทุกฟิลด์หลักในแอพคำนวณจากสูตรล้วนใน `src/utils/lannaCalc.ts` (พอร์ตจากตัวคำนวณ Python อ้างอิง `calc/lanna_calc.py`) ไม่ได้โหลดตารางข้อมูลรายปีมาแสดง:

- อัตตาสุริยยาตร์ (หรคุณ/อวมาน/มาสเกณฑ์/ดิถี) จากคัมภีร์สุริยยาตร์ กำหนดวันพญาวัน (เถลิงศก) ปีล้านนา และจุลศักราช
- โครงสร้างเดือนจันทรคติราชการ: ออก 15 ค่ำเสมอ แรม 14/15 ค่ำตามเดือนคี่/คู่ อธิกมาส (เดือนสิบสองหน) จากเกณฑ์มาสเกณฑ์
- วันไทรอบ 60, วันเก้ากองรอบ 12, ฟ้าตีแส่งเศษ, ปัญจดิถี, วันเสียประจำเดือน, วันไหม้, วันวอดวาย, วันมัจจุ, วันหัวเรียงหมอน และสิทธิโชคแบบชุดตามตำราวัดธาตุคำ
- การสะกดตามฉบับมหาวิทยาลัยเชียงใหม่: ดับใส้, ริทธาดิถี, ภัททราดิถี, อมริสสโชค, ไชยโชค, ยีเพียง, พืน, ท้ายป้าว

## การทดสอบ

สูตรผ่านการทดสอบเทียบกับ **ปฏิทินล้านนา 2569 มื้อจั๋นวันดี ฉบับมหาวิทยาลัยเชียงใหม่** (คำนวณโดย อาจารย์สนั่น ธรรมธิ) ครบ 365 วัน: ฟิลด์หลัก (เดือนล้านนา ข้าง/ค่ำ วันไท วันเก้ากอง ดิถี วันพระ ปี/จุลศักราช) ตรง 100% ส่วนฟ้าตีแส่งเศษ วันเสีย และชั้นป้าย/สิทธิโชค ตรง 358 ถึง 365 วันจาก 365 วัน โดยจุดที่ต่างคือจุดที่ฉบับพิมพ์ตกหล่นจากกฎของตนเอง ตัวคำนวณยึดกฎตำราเป็นหลัก

ตัวคำนวณ TypeScript ตรวจเทียบกับตัวคำนวณ Python อัตโนมัติ (ปี 2569 ครบ 365 วัน และตัวอย่างปี 2568, 2570, 2573 ปีละ 30 วัน) ตรงกัน 100% ทุกฟิลด์ รันซ้ำได้ด้วย `python3 ../calc/compare_ts_python.py` (สคริปต์ dump ฝั่ง TypeScript อยู่ที่ `scripts/compare-calc.ts`)
